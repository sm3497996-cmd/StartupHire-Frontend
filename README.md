# 🚀 StartupHire.in — Job Portal

**StartupHire.in** is a modern, responsive job portal designed to connect job seekers with employers. It provides an intuitive platform where candidates can explore job opportunities, manage their applications, and build their professional profiles, while employers can manage job postings and applications.

## ✨ Features

### 👨‍💻 For Candidates

* Browse and explore job opportunities.
* Search and filter jobs based on preferences.
* Create and manage candidate profiles.
* Build and update resumes.
* Apply for jobs and track application statuses.
* Save jobs for future reference.
* Access a personalized candidate dashboard.

### 🏢 For Employers

* Manage company profiles.
* Post and manage job openings.
* Review candidate applications.
* Track application statuses.
* Access a dedicated employer dashboard.

### 🎨 UI & Experience

* Modern and responsive user interface.
* Reusable React components.
* Light and dark theme support.
* Interactive job cards and filters.
* Organized navigation and dashboard layouts.
* Responsive design for different screen sizes.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Language:** JavaScript
* **Styling:** CSS
* **Build Tool:** Vite
* **Version Control:** Git & GitHub
* **Backend Integration:** REST APIs

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/StartupHire-Frontend.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Navigate to the Project Directory

```bash
cd StartupHire-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application in your browser.
